# Hall Game terapéutico interactivo

Este repositorio contiene el código desarrollado para el TFG de Ingeniería Biomédica centrado en el diseño e implementación de un Hall Game terapéutico e interactivo para personas mayores.

El sistema está implementado en Python sobre Raspberry Pi y utiliza Pygame para la interfaz gráfica, el feedback visual y la reproducción de audio.
